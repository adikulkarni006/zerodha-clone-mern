# 🚀 Zerodha Clone - MERN Stack Project

A full stack Zerodha clone built using the MERN Stack.

This project includes:
- 🌐 Frontend Website
- 📊 Trading Dashboard
- ⚡ Backend APIs
- 🛢 MongoDB Database Integration

---

# 🛠 Tech Stack

## 🎨 Frontend
- React.js
- Bootstrap
- React Router DOM

## 📈 Dashboard
- React.js
- Material UI
- Chart.js
- Axios

## ⚙ Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

# ⚡ Installation

## 📥 Clone Repository

```bash
git clone <your_repo_link>
```

---

# 🌐 Frontend Setup

```bash
cd frontend
npm install
npm start
```

Runs on:

```bash
http://localhost:3000
```

---

# 📊 Dashboard Setup

```bash
cd dashboard
npm install
npm start
```

Runs on:

```bash
http://localhost:3001
```

---

# ⚙ Backend Setup

```bash
cd backend
npm install
npm start
```

Runs on:

```bash
http://localhost:3002
```

---

# 🔐 Environment Variables

Create a `.env` file inside the backend folder:

```env
PORT=3002
MONGO_URL=your_mongodb_connection_string
```
